# scoop-bucket

Scoop bucket for [RegTool](https://github.com/ZHallen122/RegTool).

```powershell
scoop bucket add regtool https://github.com/ZHallen122/scoop-bucket
scoop install regtool
```

Manifests in this bucket are published automatically by goreleaser when a
RegTool release is tagged. Do not edit `bucket/` by hand.
